# RoamFlow AI

An AI-powered live assistant extension for Roam Research that brings real-time conversations, intelligent workflows, and contextual AI support directly into your graph.

---

## 🚀 Features

* 💬 Real-time AI chat inside Roam
* 🧠 Context-aware assistance using your graph
* 🎤 Voice interaction and live prompting
* 📄 Chat with notes, pages, PDFs, and references
* 🔍 Smart search and query support
* ⚡ Productivity automation with AI workflows
* 🤖 Multi-model LLM support
* 🛠 Custom prompts and AI tools
* 📊 Structured outputs including tables, diagrams, and code

---

## 🧩 What is RoamFlow AI?

RoamFlow AI is a browser extension designed to enhance the Roam Research experience using modern AI models. It allows users to interact naturally with their notes, automate repetitive workflows, generate structured content, and explore ideas more effectively.

The extension integrates seamlessly into the Roam interface, turning your knowledge graph into an intelligent workspace.

## 📦 Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/roam-copilot.git
```

2. Install dependencies:

```bash
npm install
```

3. Start development:

```bash
npm run dev
```

4. Load the extension in your browser developer mode.
